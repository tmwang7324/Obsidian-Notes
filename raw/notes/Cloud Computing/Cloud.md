# Overview
Cloud Computing is the on-demand delivery of computing power, database, storage, machine learning, continuous server connection, applications, and other IT resources via the internet with **pay-as-you-go pricing.** Whether you are using it to run applications that share photos to millions of mobile users ([[B2C]]) or support business critical operations ([[B2B]]/[[B2E]]), a Cloud services platform provides rapid access to flexible and low cost features.

## Benefit
With Cloud Computing, I do not need to make large upfront investments in hardware, or spend a lot of time on the managing that hardware.

1. ***Agility:*** The Cloud allows me to innovate faster becasuse I can focus my valuable IT resources on developing applications rather than managing infra and data centers.
2. ***Elasticity:*** Before Cloud Computing, I had to over provision infrastructure to ensure I had enough data-holding and computing capacity to handle my business operations at the peak level of activity. Now, I can provision the amount of resources that I actually need using the ability to instantly scale up or down with the needs of my business.
3. ***Cost Savings:*** The Cloud allows me to trade capital expense (data centers, physical servers, etc.) for variable expense and only pay for IT as I consume it.
4. ***Deploy Globally in minutes:*** With the Cloud, I can easily deploy my application in multiple physical locations around the world with just a few clicks and config files. This means I can provide a global lower latency and better experience for my customers.
## Types of Cloud Computing
Cloud Computing has three main types that are commonly referred to as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
