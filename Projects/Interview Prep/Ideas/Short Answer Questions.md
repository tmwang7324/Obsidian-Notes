# What is the most exceptional thing you have ever built?

My most exceptional project is Doculyze, a RAG document analysis platform I built with Next.js, ChromaDB, and LangChain that helps 20+ students, including myself, improve our studying efficiency. The reason why I found this project so enjoyable was because it was the first time a workload dictated my architecture rather than the other way around. Embedding is slow and bursty in a way ordinary requests aren't, so leaving it in the request path meant a large upload would stall a live conversation. I moved it onto an async RabbitMQ queue behind its own containerized service, streamed chat responses over WebSockets with Redis caching for conversation context, and deployed via Docker and Kubernetes. I also tuned the retrieval layer through HyDE, Voyage AI reranking, NER-based cross-document filtering, and structure-aware chunking, verifying a ~50% retrieval accuracy gain over the baseline embedding-only pipeline with an eval harness pairing RAGAS automated metrics, as well as hand-labeled NDCG and Recall@K benchmarks. It's a small system, but it's what inspired me to work where scale truly matters.

My most recent project ranks 71 NYC neighborhoods for commercial viability, the core challenge of which was reconciling fragmented public data sources. Datasets used different geography types such as CDTA, census tract, zip code and had missing fields that couldn't be inferred without introducing bias. I built the ingestion layer to join the geography types into a single consistent boundary, and calculate a rough estimate of the business distribution of each neighborhood. Only once that boundary was trustworthy could the AI layer produce actionable insights: a semantic ranking engine using PostgreSQL vector embeddings to score neighborhoods against a business profile, K-means clustering over 72 reconciled features, survival inference using Random Forests, and an Anthropic Claude agent generating natural-language rationale for each recommendation.

### NYC Neighborhood
My NYC platform ranks 71 neighborhoods for commercial viability. Static demographic data — income, population — can't capture whether a market can absorb another business. The nuance was engineering dynamic friction metrics: a saturation index rating each business type against localized demand, anchor proximity, and category synergy.
